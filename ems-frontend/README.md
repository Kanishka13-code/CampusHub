# CampusHub — Student Task & Event Management System

CampusHub is a full-stack student management application designed to help students manage their tasks and participate in campus events.

## Features

- Student registration and login
- JWT-based authentication
- Student dashboard
- Task management
- Create, update, and delete tasks
- Mark tasks as completed
- Browse campus events
- Join and leave events
- Event registration
- Admin event management

## Tech Stack

### Frontend
- React
- React Router
- Axios
- Tailwind CSS
- React Icons

### Backend
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- Spring Security
- JWT
- Maven

### Database
- MySQL
